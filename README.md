# Calculator and Student Grade Project

This project contains three Python programs:

## Stage 1: Basic Calculator
Performs +, -, *, / operations.
Handles division by zero.

## Stage 2: Calculator with Result Check
Performs calculation and checks whether result is:
- Positive
- Negative
- Zero

## Stage 3: Student Grade Calculator
Calculates:
- Total marks
- Percentage
- Grade (A, B, C, F)
